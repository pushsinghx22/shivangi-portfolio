# Shivangi Singh — Portfolio Website
### @whatever.shivi · Fashion & Lifestyle Creator

## 🚀 Quick Start

```bash
cd shivangi-portfolio
npm install
npm run dev
```
Open **http://localhost:5173**

## 📦 Build for Production
```bash
npm run build
npm run preview
```

## ✨ Features
- Real photos in Hero & About sections
- Dark / Light mode toggle
- Custom animated cursor
- Scroll progress bar
- Loading animation
- Animated stat counters
- Infinite brand marquee (16 brands)
- Scroll-triggered reveal animations
- 7-step process timeline
- Testimonial carousel
- Contact form (mailto-powered)
- Fully responsive (mobile-first)
